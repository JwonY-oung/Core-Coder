# 退款政策
1. **申请退款条件**
- 订单未发货：可直接申请全额退款，无手续费。
- 订单已发货未签收：需拒收包裹，包裹退回仓库验收完成后处理退款。
- 订单已签收：商品需保持完好，无破损、无使用痕迹、配件齐全，支持7天内申请退货退款；人为损坏、已消耗商品不支持退款。

2. **退款时效**
- 仓库确认收到退回商品后，1‑3个工作日内发起退款；实际到账时间取决于支付渠道，一般1‑7个工作日。

3. **不予退款场景**
- 超出7天退换期限；
- 商品人为破损、缺失配件；
- 定制类、虚拟数字类商品，一经交付不支持退款；
- 已使用消耗的商品。

4. **退款路径**
退款原路退回原支付账户，不支持其他转账方式。

5. **退款申请方式**
用户可在订单详情页提交退款申请；也可联系人工客服协助发起。
