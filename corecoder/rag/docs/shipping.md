# 配送说明
1. **发货时效**
- 普通订单：付款后1‑3个工作日安排发货，法定节假日顺延。
- 预售商品：以商品详情页标注发货时间为准。

2. **配送范围**
支持国内大部分地区配送；部分偏远地区可能无法下单，以下单页面提示为准。

3. **物流查询**
订单发货后，订单详情页会更新物流单号，可直接查看物流轨迹。

4. **关于签收**
请收货时当场检查包裹外包装；若外包装破损，建议拒收或者拍照留存凭证。

5. **物流异常**
物流长时间不更新、丢件、包裹未收到，请联系客服核实处理。

6. **运费规则**
- 普通符合包邮条件订单由商家承担运费；
- 不包邮订单运费以下单结算页显示为准；
- 因个人原因退货，退回运费由用户承担；商家责任（错发、漏发、质量问题）退货，运费由商家承担。
